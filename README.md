## Repository Structure

This repository contains the laboratory programs and outputs for all 13 weeks of the Object-Oriented Programming (C++) lab course. Each weekly directory contains:
- 3 Regular Lab Programs (\.cpp\)
- 3 DIY Programs (\.cpp\)
- Single Combined Output Screenshot Document (\.pdf\)

### Weekly Breakdown
- **Week-01**: Basics of C++ & Control Structures
- **Week-02**: Functions, Function Overloading & References
- **Week-03**: Classes, Objects & Pointers
- **Week-04**: Constructors, Destructors & Constructor Overloading
- **Week-05**: Dynamic Memory Allocation & Object Arrays
- **Week-06**: Operator Overloading (Unary & Binary)
- **Week-07**: Inheritance (Single, Multiple, Multilevel)
- **Week-08**: Hierarchical & Hybrid Inheritance, Virtual Base Classes
- **Week-09**: Polymorphism, Virtual Functions & Abstract Classes
- **Week-10**: Templates (Function & Class Templates)
- **Week-11**: Exception Handling (try, catch, throw)
- **Week-12**: File Handling & Streams (fstream, ifstream, ofstream)
- **Week-13**: Standard Template Library (STL) Containers & Algorithms
